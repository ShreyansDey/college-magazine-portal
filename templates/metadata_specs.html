FILESYSTEM HIERARCHY

Edition Directory Architecture

Every magazine is an autonomous static package placed inside the college repository under magazines/<academic_year>/<slug>/.

magazines/2025-2026/cse-aura/ AUTONOMOUS PACKAGE
cse-aura/ // Unique URL slug for the magazine edition
├─ meta.json REQUIRED // Canonical manifest describing metadata, title, and category
├─ index.html REQUIRED // Micro-frontend entrypoint loaded inside the distraction-free reader
├─ cover.jpg REQUIRED // 4:3 high-resolution cover thumbnail displayed on showcase cards
├─ css/
│ └─ style.css // Scoped CSS styling custom to this departmental volume
└─ assets/
├─ editorial-team.jpg

CANONICAL MANIFEST

meta.json Specification

The scanner parses this JSON file to automatically register titles, filters, and cover graphics into the portal catalog.

canonical-meta-schema.json 
{
  "id": "cse-aura-2026",
  "title": "AURA 2026 — Departmental Journal",
  "year": "2025-2026",
  "category": "departmental",
  "sub_id": "cse",
  "description": "Annual academic journal of the Department of Computer Science & Electronics showcasing student research, computational algorithms, and creative tech narratives.",
  "cover_image": "cover.jpg",
  "tags": [
    "Computer Science",
    "Electronics",
    "Artificial Intelligence",
    "Student Research",
    "Vidyamandira"
  ],
  "published": true,
  "published_date": "2026-02-15",
  "author_team": "CSE Editorial Board 2025–2026"
}
Field Type Requirement Permitted Values / Description
id string Mandatory Unique hyphenated alphanumeric slug (e.g. "cse-aura-2026").
title string Mandatory Formal publication title as shown in catalogs (max 120 chars).
year string Mandatory Academic session string format: "YYYY-YYYY" (e.g. "2025-2026").
category enum Mandatory Strictly one of: "annual", "departmental", or "bhavan".
sub_id string | null Mandatory Department or Bhavan code (e.g. "cse", "physics", "vivek-bhavan"). Use null for Annual Patrika.
description string Mandatory Concise editorial summary describing the volume's theme and highlights.
cover_image string Mandatory Relative file name of the cover graphic (standard: "cover.jpg").
tags array[string] Mandatory List of 3–8 search keywords enabling instant search filtering.
published boolean Mandatory true to make public immediately, false to keep in pre-press review.
author_team string Mandatory Official credits of the compiling student or departmental editorial body.
ARCHITECTURAL CONSTRAINTS

Security & Sandboxing Standards

Every magazine runs as an isolated micro-frontend inside the Unified Reader sandbox.

Sandboxed Iframe Execution

Magazines are isolated from portal cookies and authentication credentials. Top-navigation escapes and invasive script injections are blocked by strict Content-Security-Policy rules.

Path Traversal (Zip-Slip) Guard

When editorial ZIP packages are ingested by administrators, every file path is validated via strict canonical resolution before disk writes, guaranteeing complete container integrity.

Autonomous Performance

All styles and assets must be self-contained in the package directory. Heavy third-party JavaScript bundles and external trackers are prohibited to preserve sub-second render speeds.

4:3 Aspect Ratio Standard

Cover graphics must adhere to a 4:3 portrait aspect ratio (recommended: 1200 x 900 px or 1600 x 1200 px) at 85% JPEG compression to maintain high-DPI clarity without bloat.
